## Errores encontrados y corregidos
1. **El rechazo de una reserva no se mostraba** (Q8). La API respondía bien (409 `student_conflict`), pero `index.html` mostraba el error y enseguida recargaba los espacios, y esa recarga borraba el mensaje. Corrección: recargar primero y mostrar el error después.
2. **Código de tutor inválido abría un `alert()` bloqueante** (T1). Corrección: mensaje dentro de la página (`#access-msg` en `tutor.html`).

Ambos errores estaban en código generado por IA y los detectó esta QA; quedan en `docs/ai-log.md`, sección 2. Las 110 pruebas automáticas siguen pasando tras corregir.
